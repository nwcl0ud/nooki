# Nooki

A tiny pixel companion that lives on your Windows taskbar: tasks, notes, clipboard history, a color picker, focus timer, music player and 15 companions with their own colors and tricks.

**Download:** grab `Nooki-Setup-x.y.z.exe` from [Releases](https://github.com/nwcl0ud/nooki/releases/latest).

Windows may show a SmartScreen warning on first install (the app is not code-signed yet): click *More info* and then *Run anyway*. After that, Nooki updates itself.
